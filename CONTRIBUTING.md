# Contributing to LOAM

Thanks for helping make LOAM better. LOAM is proprietary, closed-source software, so the ways to help are bug reports, ideas and documentation fixes.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Report a bug

1. Check [existing issues](https://github.com/majordhyan/loam-launcher/issues) and [known issues](docs/known-issues.json).
2. In LOAM, press **F1 → Start a report**. It builds a report with tokens, e-mail addresses and your Windows user name removed. Preview it, then copy it or save the diagnostics ZIP.
3. [Open a bug report](https://github.com/majordhyan/loam-launcher/issues/new?template=bug_report.yml) with your LOAM version, Windows version, steps to reproduce, and the report.

If LOAM showed a crash card, include its title and the line shown under **Evidence**.

Never post sign-in tokens, `state.json`, or Credential Manager exports. Security problems go privately through [SECURITY.md](SECURITY.md).

## Suggest a feature

[Open a feature request](https://github.com/majordhyan/loam-launcher/issues/new?template=feature_request.yml). Describe the problem first, then your idea. One idea per request.

## Suggest a documentation fix

Found a mistake or a missing step in the docs? [Open an issue](https://github.com/majordhyan/loam-launcher/issues/new?template=feature_request.yml) describing what's wrong, and we'll update it.
