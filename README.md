# LOAM

**Your worlds, ready.** A Windows x64 launcher for Minecraft: Java Edition, built with Tauri 2, React, TypeScript and Rust.

Current version: **1.8.0 (unsigned)**. See [CHANGELOG.md](CHANGELOG.md) for what changed, and `docs/artifact.json` for the installer's size and SHA-256. The installer isn't code-signed yet, so Windows SmartScreen may warn on first run.

## Run and build

Requires Windows 10/11 x64, Node 24, Rust stable MSVC, Visual Studio C++ build tools, Windows SDK and WebView2.

```powershell
npm ci
& .\scripts\dev-shell.ps1
```

```powershell
npm test
npm run build
& .\scripts\dev-shell.ps1 @('cargo','test','--manifest-path','src-tauri/Cargo.toml')
& .\scripts\dev-shell.ps1 @('cargo','clippy','--manifest-path','src-tauri/Cargo.toml','--all-targets','--','-D','warnings')
& .\scripts\dev-shell.ps1 @('npm.cmd','run','bundle')
```

NSIS output: `src-tauri/target/release/bundle/nsis/`. Installer artwork is generated by `node scripts/brand.mjs`. The final artifact and its checksum are recorded in `docs/artifact.json`. Don't distribute intermediate installers.

## Use

1. **Account.** Sign in with Microsoft (Java Edition or Xbox Game Pass), or create an offline profile for local play. If sign-in fails, LOAM names the exact cause and fix: no Xbox profile, region, child account, Family settings, an expired session, and so on.
2. **Create a game.** Choose a Minecraft release and Vanilla, Fabric or Quilt. Each game has its own saves, mods, settings, notes and tags.
3. **Play** from Home, the Library, the tray icon or Ctrl+Enter.
4. **Discover** (Alt+3) mods, modpacks, resource packs and shaders from Modrinth, filtered to what fits the selected game. CurseForge works too once you add a free API key in Settings › Integrations.
5. **Smart Drop.** Drop a `.mrpack`, mod `.jar`, shader or resource pack zip, or a folder. LOAM inspects it, shows what it will change and backs up existing content before applying.
6. **Servers** (Alt+4). Join popular community servers or your own in one click; LOAM installs the game first if needed. Community servers aren't run by Mojang or LOAM, and most need a Microsoft account.
7. **Skins** (Alt+5). A 3D studio for your skin and capes.
8. **Tray and music.** Closing can keep LOAM in the tray (Settings › General). A corner music player streams a cozy playlist through YouTube's embedded player, or controls the Spotify app through Windows' media controls with no login. Turn it off in Settings › Home & sound.
9. **Help** with F1. Reports stay on this PC; preview, copy or export them yourself. Nothing is uploaded automatically.

Offline profiles don't prove ownership and can't join online-mode servers or Realms. Minecraft files come from Mojang's official sources; the installer contains no Minecraft files, mods or Java runtime.

## Data and recovery

New installs keep games and settings in `%APPDATA%\LoamLauncher`. Older installs that already have data in the previous location keep using it until you move it. Storage migration (Settings › Storage) copies and verifies data into an empty folder you choose and switches after a restart; the original stays intact. Back up `state.json`, `games` and `backups` together. Microsoft sessions are kept in Windows Credential Manager and are never included in exports or reports.

An interrupted install reuses verified downloads and resumes partial ones where the server allows. Repair re-verifies or reinstalls official files without touching saves. An interrupted content change blocks launch until a backup is restored. Deleted games go to `trash`; restore them while LOAM is closed.
