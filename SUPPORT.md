# Support

Thanks for using LOAM. Here's where to get help.

---

## 🐛 Bug Reports

Found something broken? [Open a bug report](https://github.com/majordhyan/loam-launcher/issues/new?template=bug_report.yml)

Please include:
- Your Windows version (10 or 11, build number)
- LOAM version (Settings › About LOAM)
- The report from **F1 → Start a report** (tokens and personal paths are removed automatically)
- Steps to reproduce the issue
- What you expected vs. what happened

> Before opening an issue, check if it's already reported in [existing issues](https://github.com/majordhyan/loam-launcher/issues).
