# FAQ

## General

**Is LOAM free?** Yes. No ads, no paid tiers, no in-app purchases.

**Is LOAM open source?** No. LOAM is proprietary, closed-source software that is free to use. This repository hosts releases, documentation and issues only.

**Does it run on Mac, Linux or Windows on ARM?** No, Windows 10/11 x64 only.

**Is LOAM affiliated with Mojang or Microsoft?** No. LOAM is an independent launcher.

**Is it really lighter than other launchers?** On our test PC LOAM used 388 MB of RAM at idle, against 695–1,526 MB for Modrinth App, CurseForge and TLauncher, and 17.7 MB of disk. See [Performance](performance.md) for the method and raw numbers.

## Accounts

**Do I need to own Minecraft?** To play online servers and Realms, yes: sign in with a Microsoft account that has Java Edition. Offline Profiles are for singleplayer, LAN and offline-mode servers.

**Does LOAM see my Microsoft password?** No. You sign in on Microsoft's own page in your browser. LOAM receives a token, which it keeps in Windows Credential Manager.

**What does "Java Edition ✓" mean?** Microsoft, Xbox and Minecraft services confirmed your account has Java Edition. LOAM checks again at every launch; hover the badge to see when.

## Games and mods

**Which versions and loaders work?** Minecraft 1.16.1 and newer with Vanilla, Fabric or Quilt. See [Compatibility](compatibility.md).

**Does LOAM support Forge or NeoForge?** Not in 1.9.0. The Migration Hub can still bring a Forge or NeoForge instance's worlds and packs into a vanilla game.

**Can I bring my games from Prism, MultiMC or CurseForge?** Yes, with the [Migration Hub](importing.md): worlds, mods, configs, packs and settings in one step. Your originals aren't changed.

**Can I use my `.minecraft` folder?** Yes: drop it on LOAM's window or choose it on the import screen. Saves, mods, packs, options and server list are copied into the selected game.

**Does LOAM download mods?** Only when you ask it to: from a Modrinth link you paste, or the files listed in a Modrinth pack you import. Everything else is files you provide.

**Do I need to install Java?** No. LOAM installs the Eclipse Temurin version each Minecraft version requires.

**What happens when the game crashes?** LOAM explains the cause on the home screen and offers a one-click fix. See [Troubleshooting](troubleshooting.md).

## Privacy

**Does LOAM collect telemetry?** No. No analytics and no LOAM servers. See [PRIVACY.md](../PRIVACY.md) for every site LOAM connects to.

## Updates

**How do I update?** Download the newest installer from [Releases](https://github.com/majordhyan/loam-launcher/releases/latest) and run it; your games and settings are kept. Automatic updates will come with a signed release.
