# First run

## 1. Choose who's playing

- **Sign in with Microsoft** (recommended). Your browser opens Microsoft's own sign-in page. After you sign in, LOAM checks Xbox and Minecraft services, confirms you have Java Edition, and comes back to the front showing your Minecraft head and **Java Edition ✓**. Your password never reaches LOAM.
- **Create an Offline Profile** for singleplayer, LAN and offline-mode servers. It can't join online servers or Realms and doesn't prove ownership.
- **Later.** You can install games first and add an account from the account button (top right).

## 2. Get a game

- **New game:** press **Install**, pick a Minecraft version and Vanilla, Fabric or Quilt, review the download size, then **Install**. Files come from Mojang (and Fabric/Quilt) and are checked before use.
- **Coming from another launcher?** Press *Coming from Prism, MultiMC or CurseForge?* on the first-run screen to open the [Migration Hub](importing.md).

## 3. Play

Press **Play** (or `Ctrl ↵`). LOAM checks your account and Java, starts Minecraft and steps aside while you play. If the game stops with an error, LOAM explains why on the home screen and offers a fix. See [Troubleshooting](troubleshooting.md).

## Handy keys

| Key | Action |
| :--- | :--- |
| `Ctrl K` | Every action, searchable |
| `Ctrl ↵` | Play the selected game |
| `Ctrl N` | Install a game |
| `Ctrl 1`–`Ctrl 9` | Switch game |
| `Ctrl ,` | Settings |
| `F1` | Support & feedback |

## Where things are

Each game has its own folder under `games\` in your data folder (see [Installation](installation.md#where-your-data-lives)), named after the game and version, with its own `saves`, `mods`, `resourcepacks`, `shaderpacks` and `config`. Open it from **Game details → Open folder**.
