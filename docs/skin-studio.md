# Skin studio

Open the shirt icon in the header, or **Accounts → Skins & capes**.

- Rotate the real 3D model by dragging; scroll to zoom. Front/Back controls work without dragging. Idle/walk animation and auto-rotation are optional; reduced motion starts them paused.
- Upload a static PNG skin, 64 × 64 or legacy 64 × 32, up to 1 MB. Choose Classic or Slim arms.
- Enter a Minecraft player name or an official `https://textures.minecraft.net/texture/...` URL to fetch a skin for review. LOAM uses Mojang's profile and texture services; it does not scrape skin websites or execute downloaded content.
- **Save look** persists the validated texture and model choice locally. The bundled LOAM Field skin and LOAM Signature cape are original pixel assets generated by `scripts/skin-assets.mjs`.
- The custom LOAM cape is **preview only**. LOAM does not grant cape entitlements or modify game binaries. An Offline Profile's studio appearance does not change its in-game appearance.
- With a working Microsoft login, **Load my wardrobe** fetches the account's official skin and owned capes. **Apply to Minecraft** uploads the selected skin only after review and confirmation. Cape changes re-check ownership against Minecraft Services. Hiding an official cape is supported.

Official application remains **unverified and blocked in this build** because an approved Microsoft client registration and owning test account have not been provided. Local PNG import, live public player lookup, validation, persistence and 3D rendering have been tested independently.

Textures are capped, decoded, dimension-checked and re-encoded without source metadata. Public texture fetches accept only Mojang's exact texture host and reject redirects. Authentication tokens stay in Rust and never reach the 3D renderer. No textures are uploaded automatically.

## Sources and license decisions

- [skinview3d 3.4.2](https://github.com/bs-community/skinview3d), MIT, locally bundled; [usage and animation API](https://raw.githubusercontent.com/bs-community/skinview3d/master/README.md). Its Three.js dependencies are included in the generated notices.
- [XMCL's maintained Minecraft Services client](https://github.com/Voxelum/minecraft-launcher-core-node/blob/master/packages/user/mojang.ts) was consulted for service request formats (multipart skin upload, active cape selection and removal). LOAM's Rust client is independently written; no implementation code was copied. Live write calls are not certified by this reference.
- `png` 0.17.16 (MIT OR Apache-2.0) decodes and sanitizes bounded skin images. `reqwest` multipart support builds the official upload request.

The generated `public/third-party-notices.txt` and `docs/dependency-inventory.json` include the installed locked dependencies.
